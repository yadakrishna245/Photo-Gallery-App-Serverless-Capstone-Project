   User Browser                API Gateway              Lambda              S3
        │                           │                      │                │
        │  POST /photos             │                      │                │
        │  Authorization:           │                      │                │
        │  <token>                  │                      │                │
        ├──────────────────────────>│                      │                │
        │                           │                      │                │
        │                           │  ✅ Token valid!     │                │
        │                           │                      │                │
        │                           │  Invoke Lambda       │                │
        │                           ├─────────────────────>│                │
        │                           │                      │                │
        │                           │                      │  Generate      │
        │                           │                      │  presigned URL │
        │                           │                      ├───────────────>│

        │                           │  URL                 │                │

        │<──────────────────────────┤                      │                │
        │                           │                      │                │
        │  PUT to presigned URL     │                      │                │
        │  (with photo data)        │                      │                │
        ├────────────────────────────────────────────────────────────────────>│
        │                           │                      │                │

        │                           │                      │                │

┌──────────────────────────────────────────────────────────────────────────────┐
│                        THE FIX (ONE LINE!)                                   │
└──────────────────────────────────────────────────────────────────────────────┘

   File: s3/index.html

   BEFORE (Line ~520):
   ┌────────────────────────────────────────────────────────────────┐
   │ headers: {                                                     │
   │     'Content-Type': 'application/json',                        │
   │     'Authorization': `Bearer ${idToken}`  // ❌ WRONG          │
   │ }                                                              │
   └────────────────────────────────────────────────────────────────┘

   AFTER (Line ~520):
   ┌────────────────────────────────────────────────────────────────┐
   │ headers: {                                                     │
   │     'Content-Type': 'application/json',                        │
   │     'Authorization': idToken  // ✅ CORRECT                    │
   │ }                                                              │
   └────────────────────────────────────────────────────────────────┘

   Same fix applied to GET /photos request (Line ~600)

   │ 3. See CRITICAL_FIX.md for details                            │
   └────────────────────────────────────────────────────────────────┘

   Problem: 500 Internal Server Error
   ┌────────────────────────────────────────────────────────────────┐
   │ Solution:                                                      │
   │ 1. Run ./deploy.sh to set environment variables               │
   │ 2. Or manually set PHOTO_BUCKET_NAME in Lambda console        │
   │ 3. Check CloudWatch logs for details                          │
   └────────────────────────────────────────────────────────────────┘

   Problem: CORS Error
   ┌────────────────────────────────────────────────────────────────┐
   │ Solution:                                                      │
   │ $ aws s3api put-bucket-cors \                                 │
   │     --bucket photos-sharing-krishna-data \                       │
   │     --cors-configuration file://cors-config.json \            │
   │     --region ap-south-1                                       │
   └────────────────────────────────────────────────────────────────┘

   Problem: Images Don't Load
   ┌────────────────────────────────────────────────────────────────┐
   │ Solution:                                                      │
   │ 1. Check Lambda logs: /aws/lambda/listPhotos                 │
   │ 2. Verify Lambda has s3:GetObject permission                  │
   │ 3. Presigned URLs expire in 15 minutes - refresh gallery      │
   └────────────────────────────────────────────────────────────────┘
