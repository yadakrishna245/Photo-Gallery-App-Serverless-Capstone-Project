S3 Bucket Configuration Notes
=============================

Data Bucket: photos-sharing-aviz-data
- Status: PRIVATE (Block all public access enabled)
- Purpose: Store user photos securely
- Access: Via presigned URLs only (generated by Lambda)
- CORS: Required for presigned URL uploads/downloads

Hosting Bucket: photos-sharing-aviz-hosting
- Status: PUBLIC (Static website hosting enabled)
- Purpose: Host the frontend application (index.html, logo.png)
- Access: Public read access via bucket policy
- Website URL: https://photos-sharing-aviz-hosting.s3.ap-south-1.amazonaws.com/index.html

CORS Configuration for Data Bucket:
See cors-config.json in project root for the complete configuration.

To apply CORS:
aws s3api put-bucket-cors --bucket photos-sharing-aviz-data --cors-configuration file://cors-config.json --region ap-south-1
